# Regenerated run artifacts

This package includes no production selection manifest or freshly trained models. Notebook 02 creates `full/development/`, a new UUID run directory and its authoritative handoff only after all required stages complete. Notebook 01 creates `full/final/` from that handoff. Test/smoke artifacts belong to clearly separate locations.

Large data, model and prediction files are excluded by `.gitignore`. Preserve the executed notebooks, complete handoff archive and selected numerical evidence after your own successful Run All. A partial run or a synthetic fixture is not a production result.
